# ForenSight V1.0 Screenshots Checklist

This checklist defines the required screenshots for the GitHub repository and recruiter portfolio.
Screenshots should be taken after completing the V1.0 UI updates.

### Requirements for all screenshots
- Clean browser window without tabs or bookmarks (or use presentation mode).
- No outdated Sprint labels or debug text.
- Consistent terminology (no "Fake/Real" language).
- 1080p or 4K resolution recommended.
- Evidence used should be the neutral `FORENSIGHT-DEMO-001` test image.

## Required Shots

- [ ] **1. Main Dashboard (Empty State)**
  - View of the application immediately after login or case creation.
  - Demonstrates clean UI and initial workflow.

- [ ] **2. Evidence Acquisition + SHA-256**
  - Shows the case selected and evidence uploaded.
  - Must clearly display the SHA-256 hash to emphasize chain-of-custody.

- [ ] **3. ELA Visualization**
  - Close-up of the Error Level Analysis (ELA) panel.
  - Must show Method, Configuration, Measurements, Visualization, Interpretation, and Limitations clearly.

- [ ] **4. Noise Visualization**
  - Close-up of the Noise Residual Analysis panel and heat map.
  - Emphasize the structured presentation of statistical metrics.

- [ ] **5. JPEG/DCT Analysis**
  - Close-up of the JPEG/DCT Analysis panel.
  - Focus on the frequency bands and quantization table visualization.

- [ ] **6. Copy-Move Analysis**
  - Close-up of the Copy-Move feature matching visualization (lines connecting keypoints).

- [ ] **7. Evidence Observation Panel**
  - Close-up of the "Evidence Normalization & Observations" section.
  - Shows how raw metrics are mapped to canonical observations.

- [ ] **8. Correlation/Assessment Panel**
  - Close-up of the final assessment logic.
  - Must clearly show "Evidence Families", "Relationships", "Contributing Observations", and the final "Assessment Level" with Rule `7B-v1`.
  - Must clearly capture the "Scientific Limitation Warning" disclaimer.

- [ ] **9. Full End-to-End Dashboard**
  - A zoomed-out or scrolling stitched screenshot showing the entire workflow from Evidence Acquisition to Assessment.
  - Provides a holistic view of the explainable pipeline.
